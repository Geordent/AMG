AMG, проба карты Тбилиси, версия 2

Файлы
  index.html                       страница с картой
  sw.js                            кэш оболочки для работы без сети
  .github/workflows/pages.yml      сборка файлов карты и публикация на GitHub Pages

Запуск с телефона
  1. Settings, Pages, Source, выберите GitHub Actions.
  2. Загрузите index.html и sw.js в корень репозитория (замените старые).
  3. Add file, Create new file, имя .github/workflows/pages.yml, вставьте содержимое файла, Commit.
  4. Вкладка Actions, дождитесь зелёной галочки (первый раз несколько минут).
  5. Откройте https://ВАШ_ЛОГИН.github.io/AMG/

Проверка офлайна
  1. Нажмите Офлайн, скачайте Вся Грузия, затем Тбилиси. Покажется реальный размер.
  2. Включите галочку Только скачанное, режим полёта, перезагрузите страницу.
