## Как работаем

- Изменения кода, данных и GitHub — только по явному GO автора; commit/push — отдельным GO.
- Каждая правка: валидаторы → локальная сборка «как в CI» → браузерные проверки (`scripts/e2e/`) → после деплоя проверка живого сайта.
- Секреты не читаются и не показываются: автор кладёт значение во временный файл, скрипт записывает секрет и удаляет файл.
- Итоги — в `docs/` с датой в имени файла.
