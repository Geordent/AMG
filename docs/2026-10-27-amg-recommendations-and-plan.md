# AMG — рекомендации и план (2026-10-27)

Сводка после аудита, оптимизаций и редизайна этого дня. Подробности сделанного — `docs/2026-10-27-amg-local-vs-live-audit.md`, стиль — `docs/DESIGN.md`.

## Где проект сейчас

- Локальная версия = GitHub = сайт. Деплой стабилен: тайлы кэшируются в CI по неделе, шрифты карты и интерфейса лежат на сайте, версия кэша SW проставляется автоматически.
- Без сети работают карта (скачанные пакеты), каталог, описания, шрифты.
- Старт быстрее: данные грузятся параллельно с библиотекой карты, описания работ — после первой отрисовки (146 → 38 KB gzip на старте).
- Новый стиль «Балкон + Скетчбук»: булавки, диски «Впечатлений», кисть и баллончик для муралов и стрит-арта, заставка, «рядом пусто», поле «совет местного».

## План по приоритетам

### P1 — контент (наибольший эффект)

1. **Фото.** Собирать с указанием автора и лицензии (поле `media` уже поддерживает атрибуцию). Источники: свои снимки, Wikimedia Commons, разрешения авторов муралов и фестивалей.
2. **Практичное по «Впечатлениям»:** цена или диапазон, часы, как добраться, нужна ли бронь. Добавить поля `price_ru/en/ka` по образцу `hours_*` и проверку в `validate-experiences.mjs`.
3. **Советы местного.** Поле `tip: {ru, en, ka}` у места или работы — уже отображается в карточке и «Подробно». Одна фраза: когда прийти, откуда лучше видно, что рядом. Начать с 20 мест.
4. **Мелкие правки текста.** В `meta`/`og`/`twitter`-описаниях написано «59 впечатлений», в данных 60. Лучше убрать точное число или считать его при сборке.

Перед изменением данных — по AGENTS.md: проверка дублей ID/координат, `node scripts/validate-data.mjs`, сравнение counts до/после, отчёт в `docs/`.

### P2 — функции для туриста

1. **Готовые маршруты** («Муралы Фабрики и Марджанишвили, 2 ч пешком», «Мозаики советского Тбилиси», «Абанотубани + Нарикала»). Решение, которое нужно принять: маршруты составляются вручную (`data/routes.json`, порядок точек, время, описание) или собираются автоматически из объектов рядом. Рекомендация: вручную, 3–5 штук для старта — качество важнее количества.
2. **«Мой день»** — страница в стиле блокнота из макета: список точек с рукописным временем, линия маршрута пунктиром на карте, кнопка «открыть в навигаторе».
3. **Фильтр «открыто сейчас»** для «Впечатлений» — после того, как часы будут заполнены.

### P3 — стиль и мелкая полировка

1. Приглушить воду и реки базовой карты под палитру «балкона» (`AMG_PALETTES.light`).
2. Тёмная тема интерфейса: панели сейчас светлые и на тёмной карте выглядят ярко. Нужны тёмные значения для штукатурки и текста.
3. ~~Вернуть иллюстрации в булавки~~ — сделано 2026-10-27: все 8 типов каталога и 13 «Впечатлений» используют рисунки первой версии в новой форме (`docs/DESIGN.md`).
4. Иконки PWA и og-cover перерисовать в новом стиле.

### P4 — техника (не срочно)

1. OpenFreeMap остаётся внешней зависимостью онлайн-слоя улиц. Это осознанно: слой необязательный.
2. Счётчик abacus — внешний сервис; при его отказе сайт работает.
3. UGC «Я здесь» выключен (`AMG_UGC_ENABLED = false`) до запуска бота и фида — без изменений.
4. Повторять сверку «локально = GitHub = сайт» после серии правок (метод — раздел 1 аудита).

## Как работаем

- Изменения кода, данных и GitHub — только по явному GO (AGENTS.md). Commit/push — отдельным GO.
- Каждая правка проверяется: валидаторы, синтаксис, локальная сборка как в CI, скриншоты/smoke в браузере, затем — проверка живого сайта после деплоя.
- Итоги — в `docs/` с датой в имени файла.
