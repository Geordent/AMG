# AMG — бот «Я здесь»: дежурный режим 24/7 (2026-10-29)

Статус: реализовано локально, **не закоммичено и не задеплоено** (ждёт отдельного GO).
Решение автора: вариант с самопродлением в GitHub Actions, режим 24/7, heartbeat-коммит.

## Проблема

`contrib-bot` по `schedule` каждые 10 минут на деле запускался ~2–3 раза в сутки:
за 37 часов — 8 запусков вместо ~220, паузы 3–7 часов. Все запуски успешные,
секреты в порядке — GitHub просто троттлит расписание. Пользователь ждал ответ
часами, хотя сайт обещает «до 10 минут».

## Решение

Один job живёт ~5,5 часов и держит **длинный polling** Telegram (`getUpdates?timeout=50`):
ответ приходит за секунды. Перед завершением workflow запускает следующий такой же
(`workflow_dispatch`), получается непрерывная цепочка 24/7. `schedule` каждые 10 минут
остаётся **сторожевым псом**: если цепочка оборвалась, ближайший запуск поднимет её снова.
`concurrency: contrib-bot` гарантирует одну активную цепочку.

```
schedule (watchdog) ─┐
push (правка бота) ──┼─► job 5,5 ч: getUpdates(timeout=50) ─► ответы за секунды
workflow_dispatch ───┘        │
                              ├─ состояние AES → contrib-state
                              ├─ фид → main → deploy pages
                              └─ за 15 мин до лимита 6 ч → workflow_dispatch(mode=loop)
```

Heartbeat: раз в 14 дней (≈2 раза в месяц) в ветку `contrib-state` пишется коммит
`contrib: heartbeat`. Это не даёт GitHub отключить расписание после 60 дней без активности.

| `.github/workflows/contrib-bot.yml` | job до 360 мин; шаги `once` (ручной `mode=once`) и `loop` (schedule/push/`mode=loop`); шаг `Next shift` запускает следующее дежурство. |

Сайт (`index.html`) не менялся. Текст «до 10 минут» остаётся корректной страховкой:
в цепочке ответ обычно за секунды, а редкие паузы не превышают худший случай.

## Проверка (локально, без сети Telegram и без реального GitHub)

- `node scripts/contrib-bot-once.mjs` без токена — dry-run, как раньше.
- Фейковый Telegram API + `AMG_LOOP_SECONDS=5`: 3 сообщения → 3 ответа (ru/en/ka),
  состояние зашифровано, фид `site-0003: verified/2`, heartbeat создан.
- Один проход (`AMG_LOOP_SECONDS=0`) + фейковый API: `feed_changed=true`,
  offset подтверждён после записи состояния.
- Временный git-репозиторий + bare-origin, `GITHUB_ACTIONS=true`:
  - `contrib-state`: коммиты `contrib: heartbeat` и `contrib: state`, файлы
    `heartbeat`, `contrib-state.enc` запушены;
  - `main`: коммит `contrib: feed` запушен;
  - `gh` локально нет → `[dispatch] spawnSync gh ENOENT` (в Actions `gh` есть).
- Валидаторы: `validate-data` PASS (573/539/188/16/48), `validate-experiences` PASS (60),
  `validate-routes` PASS (4), `contrib-test` 15/15, `extract-tiles` OK.

## Эксплуатация

- Ручная проверка (быстро): Actions → `contrib-bot` → Run workflow → `mode=once`.
- Дежурство: `mode=loop` или обычный запуск по schedule/push.
- Лог: строки `[loop] start`, `[loop] updates=… replies=… corrections=… left=…s`,
  `[loop] heartbeat`, `[loop] done`; `[dispatch] pages.yml` при изменении фида.
- Если цепочка оборвалась: schedule поднимет её в пределах часов (обычно раньше).
- Откат: revert коммита; `schedule` продолжит одно-проходный режим (`mode` не задан →
  loop, поэтому для полного отката нужно вернуть прежний workflow).
- Секреты не меняются: `AMG_BOT_TOKEN`, `AMG_STATE_KEY`.

## Ограничения и риски

- GitHub Actions для public-репозитория бесплатны; цепочка занимает один job и не создаёт
  параллельных запусков.
- GitHub ToS: длинные job'ы допустимы для production-задачи проекта; нагрузка минимальна.
- Жёсткий лимит job — 6 ч, поэтому дедлайн цикла 5,5 ч и отдельный шаг продления.
- Если упавший job не продлил цепочку, schedule перезапустит её; при 60 днях без коммитов
  GitHub отключил бы расписание — этого не случится из-за heartbeat и обычной активности репозитория.
- Telegram хранит неподтверждённые апдейты 24 ч; при паузе больше суток часть отметок
  может пропасть. В дежурном режиме пауз такого размера нет.
- Если Telegram отвечает 401/403 (токен отозван) или ошибки идут подряд ≥20 раз, дежурство
  останавливается с ошибкой, чтобы не жечь 5,5-часовой job; цепочку позже поднимет schedule.
