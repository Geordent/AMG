# AMG — обложки маршрутов (2026-10-29)

Статус: **реализовано локально, не закоммичено, не опубликовано.**

## Решение
- Обложка обязательна у каждого маршрута (решение автора). Порядок: фото Commons → иконка карты → нарисованная.
- **Для четырёх нынешних маршрутов — нарисованные.** Это муралы, стрит-арт и советские мозаики: по правилам проекта (`docs/2026-10-27-amg-photos-legal-sources.md`) их фото нельзя использовать даже со свободной лицензией (права художников, Грузия без «свободы панорамы»), фото муралов — только по письменному разрешению. Commons-фото пойдут на маршруты по природе и наследию, когда они появятся.

## Что сделано
- 4 SVG-обложки в стиле «Балкон + Скетчбук» (палитра из `docs/DESIGN.md`): `icons/covers/sololaki-old-town.svg` (дома с резными балконами и колонна Свободы), `vake-murals.svg` (огромный мурал на фасаде среди деревьев), `saburtalo-mosaic-murals.svg` (панельный дом с мозаичным панно-солнцем из плиток), `varketili-open-air.svg` (три панельных дома с муралами). 4–20 КБ каждая, без внешних ссылок и скриптов.
- `data/routes.json`: у четырёх маршрутов `cover: { "type": "art", "src": "icons/covers/<id>.svg" }`.
- **Путь `icons/covers/`, а не `assets/covers/`:** `assets/` в `.gitignore` и пересобирается/кэшируется в CI (`pages.yml`), файлы туда не попали бы ни в репозиторий, ни на сайт. `icons/` уже копируется сборкой и входит в хеш версии кэша — менять workflow не пришлось.
- **Валидатор** (`scripts/validate-routes.mjs`): для `art` — путь только `icons/covers/<имя>.svg`, файл существует, это SVG (≤ 60 КБ), без `<script>`, обработчиков `on…=`, `javascript:`, `foreignObject` и внешних `href/src`. Проверено на негативных копиях: нет файла, путь в `assets/`, скрипт и внешняя ссылка, не-SVG — все отклоняются.
- Высота обложки в карточке 164 px; если файл не загрузился (например, первый запуск без сети), показывается иконка первой остановки — запасной вариант уже был в коде.

## Проверка
- `validate-routes` PASS (4); негативные фикстуры — все 4 отклонены.
- `showcase.mjs` **44/44** (новая проверка: у каждой карточки обложка загрузилась и это нарисованная, а не запасная иконка); `myroutes.mjs` 34/34; `pageerrors: 0`.
- Просмотрены скриншоты десктопа и телефона (390 px).

## Ограничения
- Рисунки — первая версия, нужна оценка автора (стиль, сюжеты). Генератор рисунков — разовый скрипт, в репозиторий не добавлялся; исходники — сами SVG, их можно править вручную или заменить.
- Офлайн: SVG кэшируются при первом показе (cache-first); при первом запуске без сети — запасная иконка.
- Обложки для будущих маршрутов (природа, наследие, вино, курорты) делаются вместе с самими маршрутами: Commons-фото с подписью автора и лицензией (валидатор требует `credit`, `license`, `source_url`) или рисунок.
