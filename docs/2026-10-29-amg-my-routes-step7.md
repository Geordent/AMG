# AMG — «Мои маршруты»: хранение на устройстве, файл, правка (2026-10-29)

Статус: **реализовано локально, не закоммичено, не опубликовано.** Ничего не уходит на сервер: данные только в `localStorage` браузера.

## Что сделано
- **Библиотека «Мои маршруты»** (`localStorage`, ключ `amg-my-routes`, до 50 маршрутов): название, список id мест, даты, пометка `from` (из какого готового маршрута). Тексты и координаты не хранятся — берутся из каталога.
- **Панель «Мои маршруты»** (кнопка «Мои маршруты (N)» в «Маршрутах» и в витрине): список с четырьмя действиями у каждого — переименовать, поделиться ссылкой, сохранить в файл, удалить; сверху «Сохранить всё в файл» и «Загрузить из файла»; подсказка «хранятся только в этом браузере».
- **Из витрины:** «Сохранить себе» добавляет маршрут в «Мои маршруты» (раньше затирал «Мой день»); после сохранения кнопка превращается в «✓ В моих маршрутах» и ведёт к списку.
- **Правка:** открытие маршрута загружает его в редактор («Маршруты»/«Мой день») со старыми кнопками ↑ ↓ ×, названием и добавлением мест из карточек; **все правки автоматически сохраняются в тот же маршрут** («✓ Изменения сохраняются в «…»»). «Очистить» отвязывает редактор и не стирает сохранённый маршрут. Несохранённый текущий маршрут можно сохранить кнопкой «Сохранить в мои маршруты»; при открытии другого маршрута спрашивается подтверждение, если текущий не сохранён.
- **Файл** `*.amg-route.json`: `{ app: "amg", schema: 1, exported, routes: [{ name, stops, created }] }` — только id мест. Экспорт одного и всех; импорт добавляет маршруты, а не заменяет.
- **Импорт устойчив к плохим данным:** не JSON, чужой `app`, другая `schema`, файл > 300 КБ — отклоняются с сообщением «Это не файл маршрутов AMG», библиотека не меняется; неизвестные места и дубли отбрасываются (сообщение показывает, сколько мест пропущено); маршрут без годных мест пропускается; названия очищаются (теги нейтрализуются, ≤ 60 знаков); чужие поля игнорируются; одинаковые названия получают «(2)».
- **Испорченное хранилище** не ломает сайт: невалидные записи отбрасываются при чтении.
- Ru/en/ka, крупные цели нажатия (46 px) на сенсорных экранах, длинные названия переносятся.

**Про линию:** линия-дуга пунктирная (точечный пунктир `line-dasharray`), как договорились.

## Ограничения
- `localStorage` может быть очищен пользователем или недоступен (приватный режим): сайт работает, но маршруты не сохранятся — для этого и есть файл. Автоматического напоминания про резервную копию пока нет.
- Переименование использует системное окно `prompt` (просто и работает везде; можно заменить встроенным полем).
- Загрузка файла через `<input type="file">`: на iOS работает, но выбор файла из приложений зависит от системы.
- Открытие сохранённого маршрута пока идёт через редактор «Мой день»; отдельного экрана «обложка + описание» у личных маршрутов нет.
- Тексты ka — рабочие переводы.
