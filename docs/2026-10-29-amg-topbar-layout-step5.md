# AMG — перераскладка верхней панели (2026-10-29)

Статус: **реализовано локально, не закоммичено, не опубликовано.** Только раскладка: новых функций и контента нет.

## Проблема
На десктопе кнопки шли двумя горизонтальными рядами. При узком окне и длинных подписях (особенно ka) ряд вылезал за экран: «Обратная связь» уходила за край на 41 px (`ka`, 800 px), ряды наползали друг на друга.

## Решение
- **Десктоп** (ширина ≥ 769 px, мышь): кнопки встают **вертикальной колонкой справа** под лупой — язык, режим карты, «Рядом», «Маршруты», «Паспорт», «Транспорт», «Офлайн», «Обратная связь». Слева остаются бренд и ряд чипов тем; чипы и «глаз» (счётчик) отступают от колонки.
- **Телефон и узкое окно** (≤ 768 px или сенсорный экран): без изменений — бургер-меню, кнопки внутри него.
- Колонка имеет собственную прокрутку при низком окне и не заходит на кнопки карты (зум, геолокация).
- Исходный перенос ряда (`flex-wrap`) оставлен как запасной вариант для бургер-меню.
- Панель витрины на десктопе сдвинута так, чтобы не закрывать чипы.

Правки только в CSS блока `#topui`/`#bar` в `index.html`, разметка не менялась.

## Проверка
- Новый сценарий `scripts/e2e/topbar.mjs`: **45/45 PASS**, `pageerrors: 0`. Размеры: десктоп 769×600, 800×700, 1024×768, 1280×720, 1360×860, 1920×1080; телефон 390×800, 360×640, ландшафт 800×360; языки ru, ka, en. Проверяется: нет пересечений между бренд/лупа/бургер/кнопки/чипы/«глаз», ничего не выходит за экран, колонка не заходит на кнопки карты.
- Повторно прогнаны `showcase` (26), `passport-day-report`, `route-name-copy`, `search-pulse-route` — без FAIL.
- Просмотрены скриншоты: десктоп 1360 (ru), 800 (ka), телефон 390 (ka).

## Ограничения
- Окно ниже ~500 px по высоте на десктопе: колонка прокручивается внутри себя.
- Прочие e2e-сценарии (`ofm-packhint-help`, `offline-packs`, `photos`, `language`, `bot-here`, `street-view-loader`) не перепрогонялись — раскладки не касаются клики по кнопкам панели.
- Решения автора по порядку: далее дуги и «герои» (с проверкой, что дуга не выдаётся за дорогу, и `prefers-reduced-motion`), затем «Мои маршруты» + файл, обложки и контент. Commit/push — по отдельному GO.
