# AMG — раскладка верха, возврат к маршруту, движение «героев» (2026-10-30)

Статус: **реализовано локально, не закоммичено, не опубликовано.** Основа — замечания автора после просмотра промежуточного результата.

## Что сделано

**1. Возврат к маршруту (панель больше не «одноразовая»).** Пока маршрут выбран, а его панель скрыта (карточка места, любая другая кнопка), под рядом тем висит тёмная кнопка «↩ Название маршрута» с крестиком. Нажатие возвращает панель с остановками (точки и дуги остаются на карте), крестик убирает маршрут. Работает после перехода к объекту, после «Паспорта», «Рядом», «Мои маршруты» и т. д.

**2. Раскладка десктопа.**
- **Язык и стиль карты** — вверху справа от баннера проекта, в одной строке с ним. На телефоне они остаются в бургер-меню (ничего не менялось).
- **Счётчик просмотров** — внутри баннера проекта, справа в строке ссылок «Конфиденциальность · Лицензии · 👁 N» (раньше висел отдельно под рядом тем).
- **Остальные кнопки** («Рядом», «Маршруты», «Паспорт», «Транспорт», «Офлайн», «Обратная связь») — выезжают из-за правого края: в покое виден только узкий язычок ‹ у правого края (под рядом тем), карта свободна. Выезжают при наведении мыши на язычок или панель, при фокусе с клавиатуры (Tab), закрепляются кликом по язычку (повторный клик по язычку или по карте снимает закрепление). После ухода мыши панель убирается с небольшой задержкой. Учтён `prefers-reduced-motion`.
- Телефон и узкое окно: бургер-меню, без изменений.

**3. Движение «героев».**
- **Турист шёл задом наперёд:** рисунок смотрит влево (рюкзак справа), а зеркалился при движении на запад. Теперь зеркалится при движении на восток и смотрит по ходу в обе стороны.
- **Рывки на коротких звеньях:** «герой» был маркером MapLibre, который округляет положение до целого пикселя; на коротком звене за 3 с это превращалось в ступеньки. Теперь «герой» — собственный элемент с дробным смещением (`translate3d`), поворот самолётика — по касательной к дуге со сглаживанием (а не по отрезкам ломаной), обновление линии адаптивное (20 мс для коротких маршрутов, 50 мс для длинных). Добавлены мелкие «живые» движения: качание змея и шара, подпрыгивание шага туриста.
- Скорость (3–5 с на звено, пауза у точки) оставлена по прошлому решению автора.

## Ограничения
- На сенсорных ноутбуках с основной мышью выезжающая панель работает так же (наведение/клик); на устройствах с основным касанием — бургер.
- При очень низком окне (< 500 px по высоте) выезжающая панель может быть выше доступного места — прокрутка внутри панели не делалась, чтобы не обрезать язычок.
- Тексты ka — рабочие переводы.
