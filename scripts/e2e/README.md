# Браузерные сценарии (e2e)

Playwright + установленный Microsoft Edge (`channel: 'msedge'`; под Chrome замените на `'chrome'`). Запускаются вручную перед
крупными правками интерфейса, **в CI не входят** (нужен браузер и сеть).

```bash
npm i --no-save playwright-core@1.48.2      # не попадает в package.json
node scripts/e2e/assemble.mjs site-test     # тестовая копия сайта «как в CI»
node scripts/e2e/language.mjs site-test shots
```

Сценарии принимают `<папка сайта> <папка скриншотов>` (`photos.mjs` ещё и корень репозитория третьим аргументом) и печатают
`PASS`/`FAIL` по пунктам и `pageerrors`. Каждый поднимает свой временный сервер с поддержкой Range на своём порту.

| Файл | Что проверяет |
|---|---|
| `passport-day-report.mjs` | штамп «Я здесь», паспорт, «Мой день», ссылка `#route=`, «Сообщить о проблеме» |
| `bot-here.mjs` | ссылка на `@artmap_georgia_bot`, значок «проверено», коррекция точки |
| `search-pulse-route.mjs` | поиск (ru/en/ka), пульс выбранного объекта, прорисовка маршрута, телефонная раскладка |
| `ofm-packhint-help.mjs` | OpenFreeMap только вне городов с паками, подсказка «скачайте карту», справка по маршрутам, GoatCounter (долгий, ~4 мин) |
| `offline-packs.mjs` | 11 пакетов в панели «Офлайн», детальный слой Батуми, скачивание и режим «только скачанное» |
| `ready-routes.mjs` | готовые маршруты, ссылка `#ready=` |
| `route-name-copy.mjs` | название своего маршрута (в ссылке `&n=`), показ у друга, «Скопировать списком», защита от вредных названий |
| `street-view-loader.mjs` | «Посмотреть на улице», текст заставки |
| `language.mjs` | язык заставки и сайта совпадают, выбор запоминается |
| `photos.mjs` | фото Commons в карточке «Впечатления» и галерее «Подробно» |

Замечания:
- Тесты опираются на конкретные данные (`site-0003`, `site-0039`, готовые маршруты, фото); при правке этих данных ожидания надо обновить.
- В среде без видеокарты (SwiftShader) карта рисуется медленно: ожидания в тестах с запасом, загрузка картинок в «Подробно» — ленивая.
- Для `offline-packs.mjs` и `ofm-packhint-help.mjs` в тестовой копии нужны все `tiles/*.pmtiles`.
  Недостающие пакеты можно взять с live-сайта: `curl -o tiles/batumi.pmtiles https://artmap-georgia.github.io/AMG/tiles/batumi.pmtiles` (имена — в `data/offline-packs.json`).
- Запросы с `localhost` GoatCounter не засчитывает — статистика не засоряется.
